# Prompt 04 — Write One Specification

```text
Read AGENTS.md, required context, accepted ADRs, the build plan, and inspect relevant current code/contracts/tests/migrations.

Write only the specification for Unit [NN]: [name], using the correct template in context/specs/.

Make the goal concrete. Document current state from evidence. Define requirements, owning boundaries, non-goals, compatibility, security/failure behavior, dependencies, tests, and objective completion checks. Ask before choosing any missing product or architecture rule that materially changes behavior.

Do not implement the specification.
```
