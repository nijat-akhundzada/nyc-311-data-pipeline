# Prompt 01 — Discover the Project

```text
Help me define a software project before any implementation begins.

Project idea: [2–5 sentences]

Ask one focused question at a time. Clarify users, core journeys, measurable goals, scope, exclusions, data, access control, integrations, failure cases, constraints, deployment, and major technical risks. Push back on vague or conflicting answers. Separate current requirements from possible future ideas.

When the important decisions are clear, summarize:
1. Product definition and users
2. Core journeys
3. In-scope, out-of-scope, and deferred behavior
4. Technical constraints and unresolved decisions
5. Recommended context documents and profiles

Do not generate implementation code.
```
