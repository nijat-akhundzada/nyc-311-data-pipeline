# Session Archive

Use this directory for detailed historical implementation notes that no longer belong in the live progress tracker.

Name files `YYYY-MM-DD-short-topic.md` and record:

- specification worked on;
- files and behavior changed;
- contracts and migrations;
- verification commands and exact outcomes;
- decisions and unresolved issues;
- commit hash when applicable.

The current truth must remain in the core context documents. Session notes are supporting history, not a higher-priority source of truth.
