# Prompt 03 — Create the Build Plan

```text
Read AGENTS.md and all required context. Inspect the existing repository if one exists.

Create context/specs/00-build-plan.md for the approved milestone.

Each unit must have one coherent, verifiable outcome. Put decision and audit units before implementations that depend on them. Order foundations, security, contracts, data changes, behavior, integrations, cross-system testing, and operational gates by dependency. Do not force artificial UI/backend separation when one small vertical slice is safer, but split work that crosses unrelated boundaries.

For every unit provide: number, type, filename, outcome, dependencies, and initial status. Identify unresolved questions that block specification writing. Do not implement anything.
```
