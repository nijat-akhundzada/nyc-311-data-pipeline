# Prompt 06 — Review Implemented Work

```text
Review the implementation of context/specs/[NN-name].md without assuming the implementation report is correct.

Read the spec and relevant context, then inspect the diff, code, contracts, migrations, and tests. Check correctness, scope, security, authorization/isolation, failure handling, compatibility, data integrity, concurrency/idempotency, observability, and documentation accuracy as applicable.

Run safe relevant verification. Report findings by severity with file references and explain user/system impact. Distinguish defects from optional improvements. If no defects are found, state residual risks and unrun checks. Do not modify code unless asked.
```
